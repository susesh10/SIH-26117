# SIH26117 – Sovereign On-Premise Agentic AI Workbench

**Fully offline, air-gapped AI workbench** for confidential industrial work using open-weight multimodal LLMs.

> **Motto:** *Sovereign AI for Confidential Work — Nothing Leaves the Premises*

---

## Problem Statement (SIH 2026)

**Organization:** Mangalore Refinery and Petrochemicals Limited (MRPL)  
**Category:** Software | **Theme:** Smart Automation

Refineries and industrial plants generate highly confidential documents (inspection reports, P&IDs, approval notes, engineering calculations, etc.). These cannot be sent to cloud AI tools.

This project builds a **self-hosted, air-gapped AI workbench** that runs entirely on the organisation’s own hardware. Nothing leaves the premises.
